# 0008 — How-to-Baseline

- Das Baseline-Bundle der `pm/how-to/*.md`-Konventionen liegt unter `app/_share/setup/howto-baseline/` als versionierte Snapshot-Kopie.
- Fortgeschrieben wird das Bundle **per Hand**, sobald eine `pm/how-to/*.md`-Konvention sich aendert; es gibt keinen Auto-Sync.
- Inhalts-Drift zwischen Live-Datei und Baseline meldet der Setup-Check als `warn` ohne Repair-Button — die Aktualisierung ist Userin-Sache.
